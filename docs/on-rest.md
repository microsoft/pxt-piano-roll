# on rest

Runs some code whenever a rest from a piano roll editor is played. The parameter passed to this function is the duration of the rest in milliseconds.

```sig
pianoRoll.onRest(function(duration: number) {

})
```

## Parameters

* **duration**: The duration of the rest in milliseconds

```package
pxt-piano-roll=github:microsoft/pxt-piano-roll
```
