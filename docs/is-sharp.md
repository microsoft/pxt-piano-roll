# is sharp

Returns true if the note for the given note index (0-12) is a sharp or flat note. In other words returns true if the note would be a black key on a piano.

```sig
pianoRoll.isSharp(0)
```

## Parameters

* **noteIndex**: The index of the note (0-12)

```package
pxt-piano-roll=github:microsoft/pxt-piano-roll
```
