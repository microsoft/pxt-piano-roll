# pxt-piano-roll

A Microsoft MakeCode extension for micro:bit that allows you to create melodies using a piano roll editor.

This extension also includes events that fire when a note starts or ends, as well as when a rest is played, so you can run code in response to your songs!


## How to use

Open a project in the [Microsoft MakeCode editor fro micro:bit](https://makecode.microbit.org/) and click on the **Extensions** button in the **Advanced** section of the toolbox. Search for `piano-roll` and click on the extension to add it to your project.
